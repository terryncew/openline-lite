# Benchmarks

`results/reference-cl100k.json` is generated by:

```bash
pip install '.[benchmark]'
olp-lite benchmark \
  --depths 1,2,4,8,16,32 \
  --iterations 50 \
  --tokenizer tiktoken:cl100k_base \
  --out benchmarks/results/reference-cl100k.json
```

The result records its Python, platform, `cryptography`, tokenizer, tested depths, retention rule, timing, stored bytes, prompt tokens, break-even depths, and all decision fixtures.

Token counts and decisions are deterministic for a fixed version and tokenizer. Timing and peak allocation are machine-specific. See [../BENCHMARK.md](../BENCHMARK.md) before interpreting the file.
