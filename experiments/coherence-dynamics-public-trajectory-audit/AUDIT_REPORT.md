# Audit execution report

## What is now automated

The public-data audit is wired for a network-enabled GitHub Actions runner. The workflow verifies the frozen source and hostile tests before any network access, downloads exactly the pinned Nebius dataset revision, streams only the four declared source columns, prepares label-blind features, runs the frozen grouped analysis, verifies hashes and result receipts, and uploads bounded artifacts.

The workflow never receives or references an OpenAI key. It creates no model assignment and spends no API credit.

## Scientific question

The audit asks whether observable structural features in saved coding-agent trajectory fractions predict independently evaluated issue resolution and whether Coherence Dynamics curvature/CSD candidates add held-out PR-AUC beyond ordinary trajectory counts and churn.

The complete Experiment 003 mapper is not claimed. Only its exact integer curvature kernel is reused. Rolling variance and lag-1 autocorrelation of κ are the predictive candidates, consistent with Coherence Dynamics v1.2.

## Important limitation

The four fractional cut points require the completed trajectory length. They are retrospective normalized horizons, not deployable real-time trigger points. A positive result would justify a later preregistered fixed-step or clock-time audit; it would not by itself establish live early warning.

## Result boundary

The networked run may return only one of:

- `CD_ADDS_HELDOUT_SIGNAL`
- `BASELINE_OUTPERFORMS_CD`
- `BASELINE_EQUIVALENT`
- `NO_RELIABLE_SIGNAL`

No other metric can rescue the comparison. No claim about human handoff corrections, universal Coherence Dynamics, Φ*, VKD, or the Terrynce Curve is authorized.
